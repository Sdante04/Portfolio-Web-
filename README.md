# Portfolio Web — Santiago Dante Couto

Portfolio web personal para presentar mi perfil profesional, proyectos y habilidades técnicas con mayor profundidad que un CV tradicional.  
Incluye secciones orientadas a **demostrar capacidades reales de ingeniería** (proyectos, stack, “mini-lab”/demos) y una estética tipo producto tech.

## Features

- Landing/Hero con propuesta de valor y acceso directo a proyectos
- Sección **Proyectos** con caso de estudio destacado
- **Skills demostrables** (no solo “lista de tecnologías”)
- Timeline de **Educación / Certificaciones**
- Sección “Probá mi código” (API / Forecast / ETL) *(según implementación)*
- Responsive (Desktop / Tablet / Mobile)
- Micro-interacciones (hover, reveal, etc.) *(según implementación)*

## Tech Stack

- CSS / Tailwind
